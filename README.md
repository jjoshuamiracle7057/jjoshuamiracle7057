## 🚨 AI-Powered Search & Rescue Robot

An intelligent disaster-response robotic platform combining:

* 🤖 Autonomous navigation
* 👤 Human detection
* 📷 ESP32-CAM computer vision
* 🧠 YOLO-based detection
* 🔥 Fire and hazard detection
* 📡 LoRa communication
* 📍 GPS tracking
* 🌡️ Environmental monitoring
* 🚧 Obstacle detection
* 💧 Emergency water-pump system
* 🦾 Robotic/mechanical actuation
* 📊 Real-time monitoring dashboard
