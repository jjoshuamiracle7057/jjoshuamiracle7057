- 👤 Human detection

- 🔥 Fire and hazard monitoring

- 📍 GPS tracking
- 🌡 Environmental monitoring
- 🚧 Obstacle detection
- 💧 Emergency pump system
- 🦾 Robotic/mechanical actuation
- 📊 Real-time IoT dashboard
